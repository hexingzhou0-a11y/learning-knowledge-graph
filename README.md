# 学习知识图谱 · 课程依赖查询工具

**[English](README.en.md)** | 中文

一个**纯静态网页**：输入一个知识点，立刻看到它的 **前置依赖**（必须先学什么）和 **后续可学**（学会后能学什么）。

- 📚 1590 个知识点、3221 条依赖关系，**全部内嵌、离线可用**，无需联网
- 🇨🇳 界面与核心知识点**中文**显示，支持中文同义词搜索（如「一元一次方程」「正负数」「同类项」）
- 🚀 **无需安装**，下载解压后双击 `index.html` 即可打开
- 🎯 数据来自 [Marble Skill Taxonomy](https://github.com/withmarbleapp/os-taxonomy)（英美 4–15 岁数理），**对初一数学高度通用**

---

## 快速开始

**最简单 —— 直接下载离线包：**

1. 前往本仓库的 [Releases](../../releases) 页面，下载 `学习知识图谱-离线版.zip`
2. 解压到任意位置
3. 双击文件夹里的 **`index.html`**，用浏览器打开即可

**用本地服务器（推荐，体验更稳）：**

```bash
cd curriculum-graph
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 怎么查（使用说明）

1. **搜索**：顶部搜索框输入中文或英文，如 `一元一次方程`、`正负数`、`力`、`linear equations`，下拉里点一个结果。
2. **初一重点**：左侧默认标签，列出了初一数学最核心的知识点，直接点开看。
3. **按学科浏览**：切到「📚 按学科浏览」标签，按 学科 → 领域 翻找（仅显示 9 岁以上知识点）。

选中一个知识点后，你会看到：

- 🟦 **前置依赖**（每条标注**硬性/软性**依赖，并附原因）
- 🟩 **后续可学**（掌握后能解锁的内容）
- ✅ **掌握标准** · 🗣️ **口头检验** · **对应课标**

> 💡 **核心用法**：孩子某个知识点卡住时，点开它，沿「前置依赖」往上找，定位到真正没掌握的那个「地基」，对症补。每个依赖项都可以点进去继续追溯。

## 项目结构

主代码在 [`curriculum-graph/`](curriculum-graph/) 目录：

```
curriculum-graph/
├── index.html              ← 网页入口（双击打开）
├── app.js / viz.js         ← 核心逻辑（搜索、图遍历、可视化、渲染）
├── style.css               ← 样式
├── data/                   ← 内嵌数据（知识点、依赖、课标、中文翻译）
├── scripts/                ← 数据打包脚本 + 翻译源
└── 部署说明.md             ← 如何发布到网上
```

更详细的开发说明见 [`curriculum-graph/README.md`](curriculum-graph/README.md)。

## 修改 / 补充中文翻译

中文翻译集中在 `curriculum-graph/data/glossary.zh.js`，每个知识点格式：

```js
"mt_QhFEDyIwSO": {
  n: "解一元一次方程",                 // n: 中文名（搜索主依据）
  a: ["一元一次方程", "解方程"],        // a: 同义词（可选，助搜索）
  d: "用代数方法解…",                  // d: 中文描述（可选）
  e: ["能解一步…", "能解需要去括号…"]  // e: 中文掌握标准（可选）
}
```

上游 os-taxonomy 数据更新后，重新打包：`cd curriculum-graph && node scripts/build-data.mjs`

## 数据来源与许可

- 数据来自 [Marble Skill Taxonomy (os-taxonomy)](https://github.com/withmarbleapp/os-taxonomy)
- 属于**英美 IB 体系**，不含中国课标。**数学高度通用**，科学可作拓展，英语/历史/语文不适用
- 这是**学习路径参考工具，不是题库**——价值在于「看清知识点之间的依赖关系、查漏补缺」
- 许可证：ODbL 1.0（数据库）+ CC BY-SA 4.0（文本内容），使用需署名 Marble，详见源项目
